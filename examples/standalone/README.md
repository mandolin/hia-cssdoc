# CSSDoc Standalone Example

This example exercises authored CSS, PostCSS-generated CSS and Design Tokens
Format Module 2025.10 inputs with one JSON config.

From the repository root:

```sh
npm run smoke:standalone
```

The command writes extraction artifacts, HIA documents, direct-source
documentation maps and `cssdoc.producer-result.json` under `dist/cssdoc`.
Source content is not embedded by default.
